# AgeeBgee Solutions, LLC

We build Azure-native B2B software that deploys inside **your own Azure subscription**, plus a consumer digital-legacy planning platform. Based in Dunedin, Florida.

## Products

| Product | What it does |
|---|---|
| [**InsightForge**](https://ageebgeesolutions.com/insightforge/) | Email delivery observability for Postmark, Azure Communication Services, and SendGrid: bounce tracking, header inspection, and per-message flight tracking, deployed in your own tenant. |
| [**BulkForge**](https://ageebgeesolutions.com/bulkforge/) | Compliance-first bulk email orchestration for Azure enterprises. We host the control plane; a customer-deployed agent sends, so delivery credentials stay in your tenant. |
| [**Vigil**](https://ageebgeesolutions.com/vigil/) | Azure Key Vault expiry monitoring: alerts before secrets, certificates, and keys expire. Runs entirely in your subscription. Free tier available. |
| [**Dad Is Dead**](https://dad-is-dead.com/) | Digital legacy planning for individuals: custodian management, proof-of-life check-ins, and secure document storage, so the right people can get to what matters when you can't tell them. |

## How we build

- **Your tenant, your data.** The B2B products deploy into the customer's Azure subscription rather than routing your data through ours.
- **Observability by default.** If a system isn't measured, it isn't managed.
- **Simplest architecture that solves the problem.**
